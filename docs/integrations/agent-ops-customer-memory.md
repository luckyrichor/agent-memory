# agent-ops-platform P7 专用顾客记忆契约

2026-10-29，Codex。调用方获用户批准的集成；本文件只同步契约，不修改当前服务API、评测配置、数据库或运行任务。

调用方固定SDK/独立实例使用 agent-memory@1e2730c，不能把本工作区正在进行的后续评测实现混入已锁定版本。平台自己的HS256令牌禁止转发；顾客身份映射为独立tenant UUID/sub UUID，由后端持专用RS256密钥签发，受众/签发方仅对应平台专用memory实例，默认300秒（配置范围60–600秒），权限仅memory:read/write、无共享workspace/admin。

每顾客租户只在第一次实际导购时创建，业务只使用user_global scope；必须以不同租户RLS覆盖固定版按租户单条读取的边界。不能仅靠共享租户中的subject_user_id过滤保证猜ID不可见。跨顾客单条、版本、生命周期、search/context、过期/错误受众均由调用方真实API+非owner PostgreSQL测试验证。

幂等复用(tenant,key)、内容摘要、冲突409及事务锁。调用方先保存稳定操作与首次正文，键为commerce:v1:<mapped-user>:<operation>:remember；网络响应丢失重试保持正文/key。现有记忆创建幂等记录七天有效，超过七天未知操作不盲重发；调用方保留成功快照和删除后旧操作拒绝标记。

固定API没有整租户清理接口。本阶段没有为本服务新增接口；调用方只在**其专用隔离数据库**中使用版本固定管理适配器，以非owner/NOBYPASSRLS角色设置app.current_tenant_id，清理该租户九张数据表。该库不运行其他服务或提取/embedding worker。调用方先持久化deleting门控，等待在途操作结束；失败继续阻断可重试，成功清除操作正文/结果并撤销旧身份，下一次新导购才重新分配租户。

此管理适配器依赖固定schema，升级本服务前必须重验表覆盖、外键、RLS及后台worker竞争；不能无审查用于共享评测库。删除指在线数据，不声称清除历史WAL或离线备份。未登录返回401；缺配置不创建身份、不调用服务。租户数量增长开销未验证。

部署、密钥轮换、完整接口及结果以调用方docs/p7-shopping.md和docs/reports/p7-2026-10-29为准。本服务工作区另有进行中的评测修改，未纳入本次契约提交，也未由本次操作提交或发布。
