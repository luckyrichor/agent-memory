## 外部基线与被测对象

- 无记忆：不给历史。
- 全文：所选会话完整历史，不以参考答案选择来源。无人工设置的短上下文上限；供应商超限失败须单列，不冒称成功截断。超长截断与真实分词仍须实际验证后才能声称完成。
- 朴素向量：冻结Ark1024维真实向量，全量精确余弦排序，无词法、过滤、融合、阈值。与被测系统相同输入，不能以词法伪装向量。
- 系统：冻结B0公开API/SDK、真实非属主PostgreSQL。直写按原文有界分块；全链路走事件/Outbox/抽取worker。B0候选生命周期保持原样，不擅自激活；缺可用记忆是观测结果。
- 不明角色的公开源记录映射为明确的tool.result，不伪造user/assistant；原角色与原时间保留在映射，导入接收时间不冒充历史时间。其限制在报告解释。
