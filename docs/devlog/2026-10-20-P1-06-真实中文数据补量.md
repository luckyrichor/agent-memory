# P1-06：真实中文来源补量与原生参照审核

执行：Codex；北京时间 2026-10-20。原始用户方案不修改。

## 任务与边界

本轮仅 agent-memory 阶段1。先诊断旧候选未被共同保留的原因，再扩展未用 DuLeMon、接入 PerLTQA 原生标注与完整 ECD。
指南语义、指标定义、数据切分方法与验收标准保持；负责人人工答案不由助手提供。具体模型组合须按本次用户指令执行，更换需先确认。

## 实现

- `evals/chinese_expansion.py`：按旧标签原因码生成互斥诊断，明确自动原因归类不等于人工真值；保留缺证、分歧与不通顺未测量的边界。
- DuLeMon 排除旧取样索引，以固定种子抽取完整原始会话；原生说过/没说过的人设作为独立参照，模型输入不含参照标签或字段名。去分词空格，不添加事实。
- 新样本继承已冻结的全库来源切分；旧子集切分和旧结果保留、不用于混算。不存在通过重新切分来提高保留率。
- PerLTQA 原生记忆记录与对话按作者标注接入；论文明确其为模型生成并经人工修订，单列公开合成基准，不计入真实中文规模。
- ECD 校验原件大小、ZIP CRC，训练集按完整上下文去重后固定种子蓄水池抽样。只用正确回复行构成完整会话，不把回复匹配负例当作记忆负例。来源没有说话人标签，禁止按奇偶补角色。原文与审核原文不对外发布。
- `evals/reference_review.py`：原生参照审核与模型筛选解耦，生成空白、带冻结内容哈希的 CSV/JSONL；实际负责人回填后才可计算一致率。纠正前参照和纠正后结果分别保留。
- `annotate.require_disabled_thinking`：响应含思考内容或正推理 token 时拒绝正式接收，避免仅凭 HTTP 成功推断关闭思考已生效。

## 实测与阻塞

本轮指定的 DeepSeek Pro 标注中途触发免费额度耗尽；MiniMax 实测未可靠遵守关闭思考，已暂停。没有擅自更换模型、付费或拼接不完整标签。初次准备曾发现原生字段名可能通过候选ID泄漏，已中止该次运行，替换为不含标签名称的不透明ID，原件与未知用量仍保留。初次标签不接收。

所有规模、原因计数、模型调用状态、审核规模、测试结果由脚本生成，见 [本次交接报告](../reports/phase1-chinese-expansion-2026-10-20/delivery.md) 与同目录 report.json；不在此手写一套可能漂移的数字。

## 复现

```bash
uv run python scripts/prepare-chinese-expansion.py --output .local/NEW_RUN
with-tencent uv run python -m agent_memory.evals.annotate \
  --items .local/NEW_RUN/dulemon/items.jsonl --output .local/NEW_LABELS \
  --cache .local/phase1/annotation-cache --prompt docs/evals/prompts/annotation-v4.txt \
  --model deepseek-v4-pro-0813 --batch-size 50 --shards 2 --deduplicate-sources
```

命令只展示指定原模型；额度和关闭思考未恢复时不可直接当成合格双标。新输出目录不可覆盖旧证据。审核结果验证分别使用 `evals.reference_review`（原生参照）与 `evals.human_review`（ECD双模型共识与负责人仲裁），必须由真实负责人提供答案文件。

仍待：完整合格双标及κ、负责人回填、负样本整段对话比例、裁判人工校准、查询与题型覆盖；不进入阶段2。
