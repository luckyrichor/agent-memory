# 阶段 2 补测例外清单

范围：冻结业务 B0@1e9d6f3；按负责人本轮要求登记。例外不等于通过，不计入已完成测量，不触发阶段 3。

| 项目 | 本轮不能测的具体原因 | 补测条件与时机 |
| --- | --- | --- |
| O10 两种向量模型选型 | Ark 调用已被禁止，当前只允许固定腾讯 kinfra-text-embedding-0.6b；缺同一输入、另一模型的合格完整结果 | 获得明确模型对比授权及可用额度后，在独立重建索引上使用同一开发集比较；不得混用向量空间 |
| F10 换向量模型期间不停服 | 本轮固定同一向量型号，且不修改被测系统，不能擅自构造业务切换流程 | 明确批准模型切换/重建实现后，于隔离环境在持续流量下测双索引切换与回滚 |
| F11 带流量结构迁移 | 尚无真实的新版本迁移目标；执行无业务意义的结构变更不能证明正式迁移安全 | 有已审核的真实迁移与回滚脚本、升级目标后，在隔离克隆库和流量下执行 |
| 跨地域链路 | TX 与 TX2 均为上海区域；独立主机跨公网测量不能代表跨地域 | 可用另一地域的独立发压机且资源合格后，复用同一 HTTPS、数据、速率与监控方法测量 |
| nDCG | 缺完整、独立、分级相关性金标准；当前证据命中指标不能充当分级相关性 | 独立人工盲标候选相关性、规定未标条目处理方式后，冻结标注与排名池再测 |
| 幻觉率 | 缺独立的事实级支持/反驳金标准；答案正确性与人工裁判校准不覆盖每一事实 | 负责人完成事实级证据盲审规范及样本标注后再测；不借答案准确率推算 |
| 冗余率 | 缺独立的语义重复等价类金标准；字符串重复不能替代语义冗余 | 冻结独立重复判定规则并人工标注等价类后，分别测检索与上下文冗余 |
| 真实多主机时钟偏移 | 已测仅应用 now 依赖 ±120 秒，未改变不同主机 OS 时钟 | 有可隔离、可回滚的多主机时钟实验环境后测真实偏移；不在共享业务主机改时钟 |
| 完整物理删除 | 当前仅逻辑删除；正文、历史版本、备份及存储介质的清除策略未实现/批准 | 明确删除与备份保留策略、实现清除流程后，测在线库、历史版本、备份生命周期和可恢复性；介质级删除需存储侧证明 |
